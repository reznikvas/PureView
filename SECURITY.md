# Security Policy

## Supported versions

Until the first stable release, only the latest version on the default branch is
supported with security fixes.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue.

Use the repository's **Security → Report a vulnerability** flow to open a
private security advisory. If private reporting is unavailable, email Vasilii
Reznik at <reznik@halam-balam.com>. Include:

- the affected version and browser version;
- a concise description of the impact;
- reproduction steps or a proof of concept;
- whether website content, saved selectors, or permissions are exposed;
- any suggested mitigation.

The maintainer should acknowledge a complete report within seven days and keep
the reporter informed while the issue is assessed. Publication timing should be
coordinated after a fix is available.

The maintainer may publish a security advisory after a coordinated fix is
available.
