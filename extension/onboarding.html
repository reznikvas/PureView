Before you use PureView

PureView needs access to website content and browsing activity to provide its single purpose: letting you select page elements and automatically hiding everything else.

What PureView handles

  • The origin and path of pages where you save a filter.
  • CSS selectors, short element labels, and timestamps for elements you select.
  • Page DOM content temporarily, only to highlight elements and apply your saved allowlist.

How it is used

  • Settings are stored only on this device in chrome.storage.local.
  • No data is sent to the developer or any third party.
  • There are no analytics, accounts, advertisements, or remote code.
  • You can delete a site's rules at any time from the PureView popup.

PureView's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

If you do not agree, close this tab. PureView will remain inactive.
